# 工作台、装备、照明实现记录

基线：7e5b27e41a4dc212e2fb1921d359e7a3c035f07d。日期：2026-10-14。

按 reverse-engineer-anything skill 的完整源码分支执行：源码检查、入口到状态的追踪、真实浏览器运行验证。未注册或调用 REA MCP，也未获取 Minecraft 二进制。下列证据来自本仓库与测试，而非反编译结果。

| 问题 | 源码证据与实现决定 | 验证 |
| --- | --- | --- |
| 合成是否会部分扣材料 | crafting.ts 先检查数量、材料和产物容量，再一次性扣除和产出 | crafting.test.mjs 覆盖不足、容量、64 上限、创造模式和单件限制；crafting-browser.mjs 覆盖实际点击与保存 |
| 配方追踪是否随采集刷新 | RecipeTracker 由 updateInventory 更新，偏好以账号与世界为键保存；追踪一份配方 | 浏览器验证缺口变化、重新进入恢复、取消、手机宽度 |
| 工作台是否可操作 | 方块 20，edit 的放置动作命中工作台时打开合成面板；Shift 可绕过交互进行放置 | equipment-browser.mjs 使用实际射线目标、R 打开与配方制作 |
| 穿戴是否真正减伤并保存 | armor.ts 校验归属和槽位；engine.damage 调用 protectedDamage；contracts 校验装备物品存在于背包 | armor.test.mjs 验证减伤与绕过；equipment-contracts.test.mjs 校验旧存档与非法状态；浏览器验证四槽穿戴、卸下、重新进入、熔岩减伤及死亡保留／掉落；API 测试验证 PostgreSQL 往返 |
| 光源是否照亮环境 | 方块 21/22，固定 8 个 PointLight 池，按玩家距离选择；火把 10 格、灯笼 14 格；移除方块同步移除灯光来源 | lights.test.mjs 验证半径、最近 8 灯限制与释放；浏览器验证放置、激活数量、恢复和拆除；lighting-before/after 截图检查周围岩石地面变亮 |
| 旧游戏是否仍可进入 | 新装备字段默认空对象，既有编号不变，方块上限扩为 22；资源 dispose 与原生命周期一起执行 | 前端及生存浏览器回归、旧存档解析、类型检查、生产构建 |

设计边界：保留随身合成；护甲没有耐久与角色纸娃娃模型；装备仍属于背包。光源没有遮挡传播、动态阴影或燃料消耗，玩家附近最多同时 8 个发光实体。护甲只降低熔岩与预留生物攻击入口的伤害；现有生物不主动攻击。以上是本项目规则，不主张等同于 Minecraft。
